# Как сделать, чтобы сайт находили в поиске

Что в проекте уже сделано автоматически, и что нужно сделать руками (после того как сайт заработает на настоящем домене).

## Что уже сделано в коде

| Что | Зачем | Где |
|---|---|---|
| Текст страницы лежит в HTML сразу (предрендер), а не появляется после JavaScript | Поисковые роботы, особенно Яндекс, надёжнее индексируют готовый текст | `frontend/scripts/prerender.mjs`, запускается в `npm run build` |
| `<title>`, `description`, один `<h1>`, понятные заголовки разделов | Из них строится сниппет в выдаче | `frontend/index.html`, `frontend/src/content.ts` |
| `robots.txt` | Разрешает индексацию, закрывает `/api/`, указывает на карту сайта | создаётся при сборке (`frontend/vite-plugins/seo.ts`) |
| `sitemap.xml` | Карта сайта для роботов | создаётся при сборке, если задан `SITE_URL` |
| `canonical`, Open Graph, Twitter-карточка | Один «главный» адрес и красивая карточка при отправке ссылки в мессенджеры и соцсети | создаются при сборке, если задан `SITE_URL` |
| Картинка для ссылок `og-image.png` (1200×630), иконки `favicon`, `apple-touch-icon`, `icon-192/512` | Значок сайта в выдаче и на телефоне | `frontend/public/` |
| Разметка schema.org: `LocalBusiness` (телефон, зона обслуживания) и `FAQPage` (вопросы и ответы) | Поисковики лучше понимают, чем вы занимаетесь и где работаете | JSON-LD в `<head>`, тексты берутся из `content.ts` |
| Метки подтверждения владения сайтом для Яндекса и Google | Нужны для вебмастерских панелей | переменные `YANDEX_VERIFICATION`, `GOOGLE_VERIFICATION` |
| Демо на GitHub Pages закрыто от индексации (`noindex`) | Чтобы копия сайта не мешала настоящему | автоматически в режиме demo |
| Адаптивная вёрстка, быстрая загрузка, HTTPS (Caddy) | Влияют на ранжирование | весь проект |

## Что нужно сделать вам

### 1. Подключить домен и указать его адрес в настройках

1. Подключите домен по инструкции в README (шаг 8).
2. В `.env` на сервере впишите адрес с `https://` и без слеша в конце:

   ```env
   SITE_URL=https://example.ru
   ```

3. Пересоберите сайт, адрес попадает в `sitemap.xml`, `canonical` и картинку для соцсетей только при сборке:

   ```bash
   docker compose up -d --build
   ```

4. Проверьте в браузере: `https://example.ru/robots.txt` и `https://example.ru/sitemap.xml` должны открываться.

### 2. Яндекс Вебмастер

Для Хабаровска это главный поисковик, начните с него.

1. Откройте [webmaster.yandex.ru](https://webmaster.yandex.ru), нажмите «Добавить сайт», впишите `https://example.ru`.
2. Выберите подтверждение через метатег. Яндекс покажет строку вида `<meta name="yandex-verification" content="a1b2c3d4e5f6" />`. В `.env` нужно записать только значение из `content`:

   ```env
   YANDEX_VERIFICATION=a1b2c3d4e5f6
   ```

3. Выполните `docker compose up -d --build` и нажмите «Проверить» в Вебмастере.
4. В разделе «Индексирование → Файлы Sitemap» добавьте `https://example.ru/sitemap.xml`.
5. В разделе «Информация о сайте → Регион» укажите «Хабаровск» (если Яндекс сам не определил регион).
6. В разделе «Индексирование → Переобход страниц» отправьте главную страницу на переобход, это ускорит первое попадание в поиск.

### 3. Google Search Console

1. Откройте [search.google.com/search-console](https://search.google.com/search-console), добавьте ресурс «Префикс URL» `https://example.ru`.
2. Выберите подтверждение метатегом HTML, возьмите только значение `content` и впишите в `.env`:

   ```env
   GOOGLE_VERIFICATION=значение_из_content
   ```

3. Пересоберите сайт (`docker compose up -d --build`), нажмите «Подтвердить».
4. В разделе «Файлы Sitemap» добавьте `sitemap.xml`.

### 4. Карточки организации на картах (важнее всего для местной услуги)

Люди ищут «откачка шамбо Хабаровск» и видят карту с организациями. Это приводит больше звонков, чем сам сайт. Всё бесплатно:

- **Яндекс Бизнес**: [business.yandex.ru](https://business.yandex.ru): добавьте организацию, укажите телефон, зону обслуживания (Хабаровск и Хабаровский район), режим работы, адрес сайта.
- **2ГИС**: [account.2gis.com](https://account.2gis.com), то же самое. 2ГИС популярен в Хабаровске.
- **Google Бизнес-профиль**: [business.google.com](https://business.google.com), отметьте, что выезжаете к клиентам (адрес можно скрыть).

Название, телефон и адрес сайта должны везде совпадать с сайтом: `Откачка шамбо`, `+7 (4212) 20-60-06`.

### 5. Отзывы и ссылки на сайт

- Попросите довольных клиентов оставить отзыв в Яндекс Картах и 2ГИС. Отзывы сильно влияют на выдачу по местным запросам.
- Если у вас есть группа во ВКонтакте или страница в соцсетях, поставьте оттуда ссылку на сайт.

## Если захотите добавить счётчик (Яндекс Метрика и т. п.)

Метрика ставит cookie и собирает данные посетителей. Сейчас сайт не использует ни cookie, ни аналитику, и политика (`frontend/legal/privacy-policy.md`, п. 3.2) прямо это говорит. **Прежде чем подключать счётчик**, измените политику, добавьте баннер о cookie и проконсультируйтесь с юристом. Иначе политика станет неправдой.

## Как проверить результат

- Выдача: через 1–3 недели после добавления в Вебмастер поищите «откачка шамбо Хабаровск». Сайт из двух страниц новый, место в выдаче зависит от конкуренции, быстро в топ он не попадёт.
- Сколько страниц в индексе: Вебмастер → «Индексирование → Страницы в поиске». Должна быть главная (политика и согласие закрыты от индекса, пока не заполнены данные оператора).
- Как выглядит ссылка в мессенджерах: отправьте адрес себе в Telegram, должна появиться карточка с картинкой.
- Разметка: [validator.schema.org](https://validator.schema.org) или «Проверка микроразметки» в Яндекс Вебмастере.

## Как поменять тексты для поиска

- Заголовок страницы и описание (то, что видно в выдаче): `frontend/index.html` (`<title>`, `description`).
- Вопросы и ответы (они же попадают в `FAQPage`): `frontend/src/content.ts`, раздел `FAQ`.
- Телефон и название: `frontend/src/config.ts`.

После правок: `git pull && docker compose up -d --build`.

## Перегенерировать иконки и картинку для соцсетей

Файлы в `frontend/public/` (`og-image.png`, `icon-*.png`, `favicon-32.png`, `apple-touch-icon.png`) сделаны скриптом `promo/make-icons.mjs` (нужен Chrome и `npm install` в папке `promo`). Скрипт лежит рядом с видео-заготовками и в репозиторий не входит, а сами картинки в репозитории есть и менять их не обязательно.
